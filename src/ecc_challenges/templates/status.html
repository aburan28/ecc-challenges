Reading these numbers

A point is counted once it is stored. {% if v2 %}Points from the new worker are also checked one by one against the curve before they enter collision search; {% endif %}ECC2K-130 points from the original worker are checked by replaying sampled batches.

Each distinguished point stands for 2d walk steps on average, where d is the challenge's DP bit count, so estimated work is points × 2d. The percentage compares that with Certicom's expected operation count. It is an estimate from point counts, not a count of verified steps.

Rho is a random search, so 100% is not a finish line: a collision can arrive earlier or later. "Collision chance so far" is the probability that one would have appeared by now, 1 − e−π/4·x² for work fraction x. Points per hour is averaged over the last {{ snapshot.rate_window_hours if snapshot else 24 }} hours because workers upload in large batches.

Counts cover this gateway only. The earlier private ECC2K-130 run's 338,034,791 distinct DP32 points were imported on 17 October 2026, and every new public point is matched against them.
