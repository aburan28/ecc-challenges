Run a worker

The published image computes ECC2K-130. Save the key as ~/.config/ecc-challenges/api-key with mode 0600. Set a distinct GPU_ID and data directory for each container. Pin the immutable image digest from the published container package for a long-running worker.

GPU_ID=0 mkdir -p "$PWD/ecc-data-$GPU_ID" docker run --gpus all --restart unless-stopped \ --user "$(id -u):$(id -g)" \ -e ECC_GPU="$GPU_ID" \ -e ECC_CAMPAIGN=ecc2k-130 \ -e ECC_API_URL=https://ecc-challenges.com \ -v "$HOME/.config/ecc-challenges/api-key:/run/secrets/ecc_api_key:ro" \ -v "$PWD/ecc-data-$GPU_ID:/data" \ {{ worker_image }}

On Modal, use the Modal launcher. On RunPod or another container host, use this same pinned image, attach persistent storage at /data, and provide the key as a mounted file or the ECC_API_KEY environment secret. Treat provider configuration containing a key as sensitive.
