# Superseded raw-coordinate predicate controls

These immutable source snapshots and receipts belong to the initial generic
walk proposal. CPU and CUDA arithmetic parity passed, but that evidence did not
establish a usable distinguished-point density on every subgroup. A later finite
control found all 32 sampled ECC2-79 G multiples have odd x; none could satisfy
the old raw-x-low-bit-zero predicate. That proposal must not be enabled.

The replacement hashes the full canonical affine point for partitioning and
DP selection, and changes the native job magic to ECCJOB03. Its controls require
at least one emitted DP in the DP1 case for every curve. Old source snapshots
and successful arithmetic receipts remain here as evidence of the scope tested.
They are superseded for worker admission and do not count as a hash-walk GPU
release gate. No production generic namespace used this proposal.
